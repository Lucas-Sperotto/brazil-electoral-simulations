# Contribuindo
Projeto público e apartidário; propostas metodológicas são bem-vindas quando são explícitas, testáveis e acompanhadas de análise de igualdade eleitoral/efeito distributivo.

1. Abra ou escolha uma issue, explicite limites e dependências.
2. Crie branch descritiva a partir de main; mudanças pequenas e PR revisável.
3. Execute testes e linters quando disponíveis; adicione fixtures sintéticas mínimas.
4. Documente fontes, fórmulas, casos de empate e tratamento de dados faltantes.
5. Não envie bases brutas completas, credenciais, informação pessoal ou conclusão empírica sem reconciliação TSE.
6. Use template de PR e espere revisão antes de merge.
